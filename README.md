# AIPickVault Desktop

AIPickVault Desktop is an AI-powered research and decision-support assistant built by Blake Mauldin.

## Features

- AI Chat
- Intelligent Search
- Weather Forecasts
- News Analysis
- Stock Intelligence
- Recommendation Engine
- Local AI Model Integration
- Research-Oriented Responses

## Installation

```bash
git clone https://github.com/bamtec70/AIPickVault-Desktop.git
cd AIPickVault-Desktop
npm install
npm start
```
